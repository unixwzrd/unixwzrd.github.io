An operational skill should make a good procedure easier to repeat. It should not make it easier to slip past the operator.

Hands-On 12A packages that boundary as a small, downloadable Python lab. It reads invented and already-sanitized evidence, checks captured status against canonical restart plans, and renders a deterministic review packet. It never calls the control plane or executes the operation it displays.

The package uses only the Python standard library. Its acceptance runner checks 14 conditions, and the unit suite contains 27 tests covering incomplete and stale evidence, malformed input, privacy failures, plan consistency, and the no-execution boundary.
