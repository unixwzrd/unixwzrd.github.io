Title:
LogGPT 1.3.5: Dots button repair, Safari toolbar downloads, and ZIP-compatible .lgpt archives

Body:
Disclosure: I develop LogGPT, a Safari extension for exporting ChatGPT, ChatGPT Work, and Dots conversations.

OpenAI changed the Dots conversation header again, so version 1.3.5 updates the download button's placement and recovery. It also adds Download current conversation to LogGPT's Safari toolbar popup. That works for Basic and Plus and uses the existing export options, progress, and cancellation without needing the in-page button to be visible. The extension still needs to be enabled and allowed on the conversation page; reload an old tab after updating if its script needs refreshing.

The other change is the file extension for Plus artifact bundles: .lgpt instead of .zip. This is still a standard ZIP container, not a new proprietary archive format or encryption scheme. The conversation JSON, available selected files, manifest, and archive layout haven't changed. JSON-only exports stay .json, and old ZIP exports don't need converting. If an older archive utility only accepts .zip, rename a copy of the .lgpt file to .zip.

The extension prepares a recognizable Finder document type for the native Extract Chat app I'm developing for macOS. That app is upcoming, not shipped yet. The aim is to make converting exported conversations into readable Markdown or HTML with local file references easier without requiring a command-line workflow.

The Dots scope hasn't expanded: main timeline and direct available attachments, not linked task or nested reply histories.

Existing Basic and Plus owners receive the app update at no additional charge. Plus is an optional one-time IAP for artifact archiving; existing Plus purchases remain valid.

Details: https://unixwzrd.ai/s/37a9f8ca8e/
