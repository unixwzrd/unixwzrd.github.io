LINKEDIN
==================================================

I added `cleanup-image` in UnicodeFix 2.0.1, but you still had to pick the image command before the tool even looked at the file. That seemed like a silly decision to make the user carry. UnicodeFix can recognize a file by its signature, so in v2.0.2 I let `cleanup-text` route recognized images to the existing local image backend. Text still takes the text path, and one command can audit a mixed set of files.

The safeguards came along too: an image cleanup writes a separate file, `--dry-run` previews the work, and recognized C2PA provenance is not quietly stripped. You have to ask for that with `--strip-provenance`. `cleanup-image` remains available if you want the dedicated command.

It is a small release, but the front door now matches what the tool already knows how to do. This is metadata cleanup, not a claim that a pixel watermark has disappeared or that an image's author has been identified.
