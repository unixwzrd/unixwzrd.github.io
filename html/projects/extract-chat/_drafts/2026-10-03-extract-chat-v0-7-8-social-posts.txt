LINKEDIN
==================================================

An exported conversation can look complete while quietly losing part of a message or pointing to a file that isn't there anymore. Those are the bugs I wanted to get out of extract-chat.

Version 0.7.8 preserves `Sources` blocks and `References` headings when they are part of the message itself, including text pasted from a document or code. It also handles exports that mix timestamps in seconds and milliseconds, and uses an unknown date instead of aborting when a timestamp is outside the supported calendar range.

This update includes the v0.7.7 archive repairs too: older ZIP filenames can be recovered when the artifact manifest confirms them, files differing only by letter case no longer overwrite each other on case-insensitive systems, and Markdown and HTML links point to preserved local artifacts rather than temporary extraction paths. The original ZIP and JSON stay untouched.

If you use LogGPT to save conversations and extract-chat to make them readable, this release is about keeping the transcript and its files together, even when the export came from a different generation of ChatGPT.

Title:
extract-chat v0.7.8: Keep the Whole Conversation and Its Files

Subtitle:
Transcript-fidelity, timestamp, and older-archive repairs for LogGPT downloads.

Body:

An exported conversation can appear complete while losing the end of a message or leaving links to files that only existed during extraction. Version 0.7.8 addresses both problems.

When a message includes its own Sources block or References heading, extract-chat now keeps that authored text in Markdown and HTML rather than confusing it with a generated section. It also handles exports mixing Unix timestamps in seconds and milliseconds. A date outside the supported calendar range becomes an unknown date instead of stopping the entire export.

The release includes the archive repairs from v0.7.7. Older ZIP member names can be recovered when the artifact manifest confirms the intended UTF-8 path. Files whose paths differ only by case remain distinct on case-insensitive filesystems. Linked artifacts are copied beside the rendered output, so Markdown and HTML don't depend on a temporary extraction directory. Derived manifests record changed output paths while preserving the original archive path; the source ZIP and JSON remain untouched.

LogGPT captures the conversation and available artifacts. extract-chat turns that local JSON or ZIP into a readable record you can keep and reprocess.
