Extract Chat 1.0.0 brings our conversation-conversion tools to a native Mac app, available soon on the Mac App Store. Drag in supported JSON, ZIP, or LogGPT .lgpt files, choose Markdown, HTML, or both, and convert locally without setting up Python.

The app handles supported ChatGPT, ChatGPT Work, Dots, and Hermes Desktop exports. Batch conversion, progress and cancellation, optional continuity chunks, and custom HTML CSS make the same archive useful for reading, research, or continued work in another conversation. Prefer a repeatable command? The app can install a launcher for its bundled engine.

Suggested title:
We're bringing Extract Chat to macOS: local Markdown/HTML conversion for ChatGPT, Dots, and Hermes Desktop exports

Suggested body:

We're the developers of Extract Chat, a local conversation-conversion tool. Version 1.0.0 adds a native Mac app, which is coming soon to the Mac App Store. The source and command-line tool are available on GitHub.

The idea is to make downloaded conversation archives useful without asking everyone to set up Python. Drag in supported JSON, ZIP, or LogGPT .lgpt files, choose Markdown or HTML, and convert them locally. The app includes its conversion engine.

Available uploaded/generated artifacts remain with the transcript, with local references in the output. Completed results also keep the original conversation JSON. Exported tool activity can be inspected in expandable sections; recorded commands are never executed. Missing files are reported as not captured, not fetched or invented.

There is batch processing with progress and cancellation, optional continuity chunks, and customizable HTML CSS. You can view the default stylesheet, save a copy, edit it in your preferred editor, and choose it for later conversions. A command-line launcher for the app's bundled engine is included as an option too.

The initial native app is for Apple silicon Macs on macOS 14 or later. Dots support covers the exported main timeline and available direct attachments, not linked tasks or nested reply histories. Hermes support is for the Desktop export format.

Body:

Downloaded conversations tend to end up as JSON files that are technically complete but awkward to read or reuse. Extract Chat turns supported exports into Markdown and HTML, keeping available artifacts with the conversation.

Version 1.0.0 brings that workflow to a native Mac app, available soon on the Mac App Store. Drag in supported files, choose the output, and convert locally without installing Python separately. The initial native release supports Apple silicon and macOS 14 or later.

The app supports ChatGPT, ChatGPT Work, Dots, and Hermes Desktop exports, with source-specific limits described in the announcement. It adds batch progress and cancellation, optional continuity chunks, inspectable exported activity, and a way to save and customize the HTML stylesheet. The command-line workflow remains available too.
