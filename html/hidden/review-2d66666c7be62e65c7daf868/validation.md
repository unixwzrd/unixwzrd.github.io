## Required Checks

The boxes below represent complete cross-path acceptance, not the existence of a type, API or unit test. None is checked at this checkpoint.

- [ ] **V1: Effective context is the ceiling.** Compute the intersection of all applicable participants' permissions. An agent's broader independent privileges must not expand what can be retrieved or injected into that conversation. Unknown participants, incomplete mappings, stale epochs and invalid policy fail closed.
- [ ] **V2: No privileged memory in shared model context.** Authorize before vector/FTS/graph candidate retrieval, ranking, evidence expansion, reranking, tool results, prompt assembly or provider submission. Do not retrieve higher-privilege material for internal reasoning in a shared conversation; it can contaminate the answer even if final output is filtered.
- [ ] **V3: All paths enforce the same policy.** Cover SDK, CLI, MCP, Hermes/other adapters, direct IDs, persona injection, caches, consolidation, export/sync, resolvers and administrative/debugging operations. Unsupported protected paths deny rather than silently fall back.
- [ ] **V4: Identity and routing are trustworthy.** Derive principals, complete participant sets, banks, projects and destinations from authenticated adapter context, not chat titles, model arguments or session labels. Exercise public/private A/B/A interleaving through actual host/provider dispatch and inspect non-target stores.
- [ ] **V5: Derivatives never become less restricted accidentally.** Summaries, extracted facts, embeddings, cached fragments and cross-agent handoffs inherit source restrictions. Traversable provenance supports immediate quarantine of affected descendants on revocation, correction or deletion; regeneration requires independently authorized supporting evidence.
- [ ] **V6: Policy changes interrupt in-flight use.** Participant, grant, purpose or policy changes invalidate affected caches and outstanding evidence handles. Define and test cancellation or authorization gates for long-running and streaming responses, including work already queued for provider submission. Already emitted text cannot be retracted.
- [ ] **V7: Protected mode cannot be downgraded.** Persist activation with the protected store. Missing configuration, older clients, restored databases and unsupported adapters must not reopen it in legacy mode. Policy rollback must not silently reinstate revoked grants.
- [ ] **V8: No side-channel disclosures.** Denials, counts, filenames, timing-sensitive diagnostics, logs and why-not-recalled tooling must not disclose restricted objects. Audit allow/deny decisions without duplicating sensitive memory or prompt content. Define a timing threat model and test observable differences; absent timing guarantees are a gap, not an implicit waiver.
- [ ] **V9: Evidence and source handling remain exact.** Source/revision/span identities survive moves and extraction corrections. Expansion reauthorizes and verifies the expected revision; offline or changed originals remain clearly marked. Keep full originals outside Mnemosyne and bound retained excerpts, including aggregate source retention.
- [ ] **V10: Prove coverage and measure cost.** Exercise denied canaries across every enabled retrieval and maintenance surface, including high-ranked forbidden matches and participant changes. Record authorization coverage, recall quality, p95 latency against a fixed baseline and every uncovered path. Zero unauthorized disclosure is a release gate.
