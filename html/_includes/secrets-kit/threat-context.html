Where do secrets turn up?

  • Code and configuration: repositories, their history and integration files. GitGuardian found 24,008 unique secrets in the MCP configuration files it studied. Configuration findings.
  • Shared work: collaboration and productivity tools can expose credentials beyond the application that needs them. GitGuardian’s non-code findings.
  • Browsers and workstations: infostealer logs contain saved passwords and other stolen browser material. Breachsense’s collection and method.
  • Build systems and container images: retained image layers and runtime environments can expose service credentials. Codecov’s incident postmortem.
A documented example of an exposed key being used

In the historical Codecov incident of 2021, an attacker extracted a cloud service-account key from a public container image layer and used it to alter the Bash Uploader. The altered uploader extracted customers’ environment variables. This establishes key misuse and downstream exfiltration—not that every exposed customer credential was subsequently used. Codecov’s account of the attack and recovery.

Where Secrets Kit helps: keep credentials out of routine project-file copies, select what an application receives, and authorize synchronization peers. It does not make a compromised application or user account safe, replace endpoint protection or breach monitoring, or revoke a leaked key at its issuer. A receiving process can still expose an injected credential. If a credential leaks, revoke or rotate it at the issuing service; deleting one copy is not enough.

Source definitions and update notes

The annual chart and averages use GitGuardian’s rounded public-code figures, not a count of valid or exploited credentials. Monthly rows describe Breachsense’s indexed collections; machine totals exclude records without a machine identifier, and the same pair or machine may appear in more than one collection. Verizon’s percentage uses non-Error, non-Misuse breaches with a known initial access vector, not every breach or security incident in its report.
